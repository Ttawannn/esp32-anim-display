Display Editor

ติดตั้งเฟิร์มแวร์ลงบอร์ด

แฟลชเฟิร์มแวร์ล่าสุดลง ESP32-C3 / ESP32-C6 SuperMini ได้จากเบราว์เซอร์ ไม่ต้องลงโปรแกรม ระบบจะตรวจชนิดชิปให้อัตโนมัติ

เบราว์เซอร์นี้ติดตั้งผ่าน USB ไม่ได้ — ใช้ Chrome หรือ Edge บนคอมพิวเตอร์ ต้องเปิดหน้านี้ผ่าน HTTPS

เวอร์ชัน __VERSION__

ขั้นตอน

  1. เสียบบอร์ดเข้าคอมด้วยสาย USBใช้สายที่ส่งข้อมูลได้ (สายชาร์จอย่างเดียวจะมองไม่เห็นบอร์ด)
  2. กด "ติดตั้งเฟิร์มแวร์" แล้วเลือกพอร์ตของบอร์ดถ้าไม่เจอบอร์ด: กดปุ่ม BOOT ค้าง แล้วเสียบสายใหม่ ปล่อย BOOT แล้วลองอีกครั้ง
  3. เลือก "ติดตั้ง"ครั้งแรกเลือกล้างข้อมูล (Erase) ได้ ถ้าอัปเดตเวอร์ชันและอยากเก็บแอนิเมชันเดิมไว้ ไม่ต้องล้าง
  4. เชื่อม Wi-Fi ของบอร์ดชื่อ DisplayEditor-XXXX รหัส displayedit แล้วหน้าเว็บของบอร์ดจะเปิดขึ้นเอง (หรือเข้า http://192.168.4.1)
