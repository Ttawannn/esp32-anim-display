Display Editor

Install the firmware on your board

Flash the latest firmware onto an ESP32-C3 / ESP32-C6 SuperMini or a 30-pin ESP32 DevKit straight from the browser, nothing to install. The chip is detected automatically.

This browser can't flash over USB. Use Chrome or Edge on a computer. This page must be opened over HTTPS.

Version __VERSION__

Steps

  1. Plug the board into your computer over USBUse a data cable (a charge-only cable won't show the board).
  2. Press "Install firmware" and pick the board's portBoard not listed? Hold BOOT, plug the cable in again, release BOOT and retry. A 30-pin ESP32 DevKit has a separate USB chip (CP2102 or CH340): if no port shows up, install that chip's driver first, and if it hangs at "Connecting", hold BOOT.
  3. Choose "Install"You can erase the first time. When updating, skip erasing to keep your animations.
  4. Join the board's Wi-FiNetwork DisplayEditor-XXXX, password displayedit. The board's page opens by itself (or go to http://192.168.4.1), and a setup wizard walks you through the rest.
